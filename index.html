Compilación Multiplataforma en GitHub Actions:

                        
                        

                            

                                1. Descargar .ZIP
                                
Presiona arriba en "Descargar Proyecto Multiplataforma (.zip)". Incluye el script en `.github/workflows/build.yml`.

                            

                            

                                2. Subir a GitHub
                                
Descomprime el archivo `.zip` y súbelo a un repositorio público o privado en tu cuenta de GitHub.

                            

                            

                                3. Obtener APK y EXE
                                
Ve a la pestaña "Actions" en GitHub. Al terminar la compilación, podrás descargar los instaladores para Android (.APK) y Windows (.EXE).

Compilación Local Automática en Windows (.EXE) en 1-Clic

                        
El ZIP descargado contiene el script `compilar_windows.bat`. Solo debes hacer doble clic en él para compilar de forma totalmente autónoma.

                        
                        

                            
¿Qué hace el archivo compilar_windows.bat?

                            
    
                                
  • Trabaja de forma independiente en la carpeta donde esté ubicado (`cd /d "%~dp0"`).
    • 
                                
  • Verifica si Python está instalado en tu sistema.
    • 
                                
  • Detecta e instala automáticamente `pyinstaller`, `pywebview` y `pythonnet` si faltan.
    • 
                                
  • Detecta automáticamente si incluyes una imagen de ícono (`icon.ico` o similar) y se la asigna al ejecutable.
    • 
                                
  • Si la compilación falla, mantiene la consola abierta con los errores detallados sin cerrarse.
    • 
                                
  • Si finaliza con éxito, muestra la ruta del `.exe` generado en `/dist/` y se cierra automáticamente.
    •

Compilación Local de Android en Linux / WSL

                        
Si utilizas Linux o el entorno WSL (Subsistema de Linux para Windows), puedes compilar el APK usando Buildozer.

                    


                    

                        
# 1. Instalar dependencias del sistema
sudo apt update
sudo apt install -y git zip unzip openjdk-17-jdk python3-pip autoconf libtool pkg-config zlib1g-dev libncurses5-dev libncursesw5-dev libtinfo5 cmake libffi-dev libssl-dev

# 2. Instalar Buildozer y Cython
pip3 install --user --upgrade buildozer cython

# 3. Compilar APK
buildozer -v android debug
